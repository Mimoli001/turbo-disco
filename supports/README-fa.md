# ماشین مجازی رایگان با GitHub Actions

[English](../README.md)

:warning: یادآوری: اگر هنگام راه‌اندازی سیستم‌ها و VPS به مشکل یا خطا برخوردید، این پروژه را Fork کنید و آخرین نسخهٔ کدهای همین مخزن را به Fork خود بکشید. مراحل در بخش «به‌روزرسانی کد» آمده است.
استفاده از آن کاملاً رایگان است؛ ماشین مجازی macOS، Windows و Ubuntu خودتان را داشته باشید.

## مشخصات ماشین:
مشخصات زیر مربوط به رانرهای استاندارد GitHub است که این پروژه در مخازن **عمومی** استفاده می‌کند (در مخازن عمومی رایگان و نامحدود است):

### ویندوز و لینوکس:
- ۴ هسته vCPU
- ۱۶ گیگابایت RAM
- ۱۴ گیگابایت دیسک SSD **(به‌جز فضای اشغال‌شده توسط سیستم‌عامل)**

### مک‌اواس (`macos-latest`، تراشهٔ اپل)
- ۳ هسته vCPU (Apple M1)
- ۷ گیگابایت RAM
- ۱۴ گیگابایت دیسک SSD **(به‌جز فضای اشغال‌شده توسط سیستم‌عامل)**

> :warning: این مشخصات مربوط به Forkهای **عمومی** است. اگر این مخزن را به‌صورت **خصوصی** Fork کنید، رانرهای لینوکس/ویندوز کوچک‌ترند (۲ هسته vCPU / ۸ گیگابایت RAM)، از ۲٬۰۰۰ دقیقه رایگان Actions در ماه کم می‌شود (ویندوز ۲ برابر و مک‌اواس ۱۰ برابر منظور می‌شود) و همزمانی مک‌اواس به ۵ job محدود است.

> :information_source: ورک‌فلوی ویندوز روی رانر Windows Server گیت‌هاب اجرا می‌شود که Remote Desktop در آن فعال است (محیط دسکتاپ شبیه ویندوز ۱۰/۱۱ است).

## راه‌اندازی:
۱. این پروژه را Fork کنید.
۲. به صفحهٔ پروژهٔ خود بروید، روی `Settings` و سپس `Secrets` کلیک کنید و با دکمهٔ `New Secret` موارد زیر را اضافه کنید:

نام Secret | کاربرد | توضیحات
----- | ----- | -----
`MAC_REALNAME` | نام نمایشی کاربر در مک‌اواس | هر نامی که می‌خواهید
`MAC_USER_PASSWORD` | رمز عبور مدیر سیستم مک‌اواس | هر رمزی که می‌خواهید
`NGROK_AUTH_TOKEN` | برای تونل‌های **ngrok** | به سایت ngrok بروید و کلید API را از https://dashboard.ngrok.com/get-started/your-authtoken کپی کنید. :warning: در پلن **رایگان** ngrok، تونل‌های TCP (SSH/RDP/VNC) نیازمند تأیید کارت اعتباری روی حساب شما هستند.
`VNC_PASSWORD` | رمز عبور احراز هویت VNC | هر رمزی که می‌خواهید
`WINDOWS_USER_PASSWORD` | رمز ورود RDP در ویندوز | هر رمزی که می‌خواهید؛ ورک‌فلو آن را به‌عنوان رمز حساب RDP تنظیم می‌کند
`LINUX_USERNAME` | نام کاربری سیستم لینوکس | هر نامی که می‌خواهید
`LINUX_USER_PASSWORD` | رمز عبور شل لینوکس و root | هر رمزی که می‌خواهید
`LINUX_MACHINE_NAME` | نام رایانه در سیستم لینوکس | هر نامی که می‌خواهید
`CHROME_HEADLESS_CODE` | برای دسترسی از راه دور به دسکتاپ لینوکس با Google Remote Desktop | کدها را از [اینجا](https://remotedesktop.google.com/headless) کپی کنید، با حساب گوگل وارد شوید و کد زیر قسمت `Debian Linux` را بردارید. :warning: هر کد فقط یک بار قابل استفاده است؛ بعد از استفاده باید کد جدیدی بسازید.
`GOOGLE_REMOTE_PIN` | PIN مورد استفادهٔ Google Remote Desktop | هر PIN حداقل ۶ رقمی که می‌خواهید؛ هنگام اتصال به دسکتاپ لینوکس به آن نیاز دارید

## استقرار و اجرا
<details>
    <summary>نصب و اجرا در مک‌اواس</summary>
<br>

۱. به تب `Actions` بروید و یکی از ورک‌فلوهای سیستم را انتخاب کنید.

۲. روی دکمهٔ `Run Workflow` در کنار خط `This workflow has a workflow_dispatch event trigger` کلیک کنید.

۳. چند دقیقه صبر کنید.

۴. به https://dashboard.ngrok.com/status/tunnels بروید و بررسی کنید که یک تونل آنلاین در حال اجراست.

۵. لینک را (**بدون پیشوند tcp://**) کپی کنید، نرم‌افزار VNC Viewer را نصب کنید و لینک را در قسمت اتصال وارد کنید.

۶. اطلاعات ورود را وارد کنید: نام کاربری `vpsuser` و رمز همان `VNC_PASSWORD` که تنظیم کرده‌اید.

۷. لذت ببرید!

</details>

<details>
    <summary>ویندوز</summary>
<br>

۱. ابتدا ورک‌فلوی ویندوز را از تب `Actions` اجرا کنید.
۲. سپس در لاگ job منتظر مرحلهٔ `Print connection info` بمانید — آدرس `mstsc /v:HOST:PORT`، نام کاربری و رمز عبور را چاپ می‌کند. می‌توانید https://dashboard.ngrok.com/status/tunnels را هم بررسی کنید.
۳. برنامهٔ Remote Desktop Connection ویندوز (`mstsc`) یا Microsoft Remote Desktop را باز کنید و با همان آدرس متصل شوید.
۴. لذت ببرید!

</details>

<details>
    <summary>لینوکس</summary>
<br>

۱. ابتدا عملیات سیستم لینوکس (SSH یا Desktop) را اجرا کنید.
۲. سپس لینک را از کنسول کپی کنید.
۳. به ترمینال مک‌اواس، CMD ویندوز یا هر کلاینت SSH دیگری بروید و دستور داده‌شده را وارد کنید و رمز ssh را بزنید (هنگام تأیید اتصال **yes** را تایپ کنید).
۴. برای دسترسی root دستور **sudo -i** را بزنید و رمز را وارد کنید.
۵. لذت ببرید! (اما فقط به مدت ۶ ساعت)

</details>


- یادآوری‌ها:
:warning: تا زمانی که متصل هستید ورک‌فلو را متوقف نکنید. ماشین (و نشست از راه دور شما) فقط تا سقف **۶ ساعت** GitHub Actions دوام می‌آورد و سپس همه‌چیز پاک می‌شود.

:warning: تا زمانی که متصل هستید روی ماشین مجازی به‌روزرسانی سیستم‌عامل (مک‌اواس، ویندوز و…) نصب نکنید؛ ممکن است سیستم ری‌استارت شود و اتصال از راه دور قطع گردد.

## به‌روزرسانی کد
<details>
    <summary>برای دیدن کلیک کنید</summary>
<br>

برای آوردن آخرین نسخهٔ این پروژه به Fork خودتان:

**روش A (در گیت‌هاب):** Fork خود را باز کنید، روی دکمهٔ **Sync fork** کنار نام شاخه کلیک کنید و **Update branch** را بزنید.

**روش B (از ترمینال):**

```bash
git remote add upstream https://github.com/Mimoli001/turbo-disco.git   # فقط برای بار اول
git fetch upstream
git merge upstream/main      # یا: git rebase upstream/main
git push
```

حالا Fork شما آخرین ورک‌فلوها و اسکریپت‌ها را اجرا می‌کند.

</details>

## محدودیت‌ها:
۱. هر ماشین مجازی حداکثر تا **۶** ساعت زمان اجرا دارد (این سقف سختِ زمان اجرای job روی رانرهای GitHub است). اگر ماشین به این سقف برسد، job خاتمه یافته و همه‌چیز پاک می‌شود.
۲. ذخیرهٔ فایل‌های مهم و حساس روی ماشین‌ها توصیه نمی‌شود؛ همهٔ فایل‌ها حذف شده و قابل بازگردانی نیستند.
۳. از آنجا که از **ngrok** استفاده می‌کنیم، پلن رایگان حداکثر **۳** تونل آنلاین همزمان می‌دهد؛ پس می‌توانید هر سه سیستم را همزمان اجرا کنید. :warning: در پلن رایگان **تونل‌های TCP (SSH / RDP / VNC) نیازمند تأیید کارت اعتباری** هستند و محدود به ۱۰۰ اتصال TCP در دقیقه، ۵٬۰۰۰ اتصال TCP در ماه و ۱ گیگابایت ترافیک در ماه‌اند (جزئیات: https://ngrok.com/pricing).
۴. ورود به حساب‌های وب‌سایت‌ها (مثل **Google** یا **Microsoft**) توصیه نمی‌شود، چون اتصال **VNC** رمزگذاری نشده و به‌راحتی در دسترس دیگران قرار می‌گیرد.
۵. Actions در مخازن **عمومی** رایگان و نامحدود است. در یک Fork **خصوصی** ۲٬۰۰۰ دقیقهٔ رایگان ماهانه بین همهٔ ورک‌فلوها مشترک است (لینوکس ۱×، ویندوز ۲× و مک‌اواس ۱۰×).
۶. در پلن GitHub Free حداکثر **۲۰** job همزمان اجرا می‌شود که حداکثر **۵** تای آن‌ها می‌تواند مک‌اواس باشد.

## پیشناهادها و ترفندها:
- اگر تجربهٔ کنترل از راه دور در **مک‌اواس** یا **ویندوز** کند و لگ‌دار است، برای سرعت و روانی بیشتر از **Google Remote Desktop** یا **Microsoft Remote Desktop** استفاده کنید.
- برای تغییر نام کاربری و نام‌های نمایشی سیستم‌ها، حتماً این پروژه را **Fork** کنید.
